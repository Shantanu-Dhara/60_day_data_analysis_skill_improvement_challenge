# Rock Paper Scissors Game 🎮

## Project Overview

This is a simple Rock Paper Scissors web application built using Python and Streamlit. The game allows users to play against the computer while keeping track of scores.

## Learning Resources

* Learned the basic game logic from a FreeCodeCamp Python tutorial.
* Explored Streamlit to convert the game into an interactive web app.
* Used ChatGPT for guidance, debugging, and improving the user interface.

## Steps Followed

### 1. Learned the Fundamentals

* Understood how Rock Paper Scissors works.
* Learned about functions, conditional statements, and the random module.

### 2. Built the Basic Game

* Created game logic for determining wins, losses, and ties.
* Generated random choices for the computer.

### 3. Converted the Project into a Web App

* Used Streamlit to create an interactive interface.
* Added buttons for Rock, Paper, and Scissors.

### 4. Improved User Experience

* Added a scoreboard using Streamlit session state.
* Implemented a reset score button.
* Added emojis and custom CSS styling.

### 5. Debugged and Enhanced the Project

* Took help from ChatGPT whenever I faced issues.
* Modified the code and added my own improvements.

## Concepts Practiced

* Python Functions
* Conditional Statements
* Random Module
* Session State
* Streamlit Components
* Basic UI Design
* Problem Solving and Debugging

## Outcome

Successfully built an interactive Rock Paper Scissors game and gained hands-on experience with Python and Streamlit. This project strengthened my understanding of Python fundamentals and web application development.
