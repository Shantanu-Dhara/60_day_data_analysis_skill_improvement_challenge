### 🧠 Topics Practiced
**Python List Concepts Covered:**
- Creating lists with mixed data types.  
- Finding the **length** of a list using `len()`.  
- Counting occurrences with `count()`.  
- Adding items using `append()` and `insert()`.  
- Removing elements with `remove()` and `pop()`.  
- Finding element position using `index()`.  
- Extending lists with another list using `extend()`.  
- Reversing a list with `reverse()` and sorting using `sort()`.  
- Iterating through lists using:
  - `for` loop  
  - `for` loop with `range()`  
  - `while` loop  
  - list comprehension  
- Practiced **list slicing**: positive, negative, and range-based slicing.  
- Used **conditional list comprehension** to filter list items.

### 💡 Key Learnings
- Learned how lists store multiple data types and can be manipulated easily.  
- Practiced multiple **iteration techniques** to process lists efficiently.  
- Understood how slicing and list comprehension simplify data handling.
