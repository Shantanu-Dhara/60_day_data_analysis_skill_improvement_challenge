### 🗓 Date
October 29, 2025

---

### 🎯 Topics Covered
- Creating and managing databases  
- Creating tables with constraints  
- Inserting multiple records  
- Altering tables (add, modify, change columns)  
- Updating specific records  
- Deleting rows from a table  
- Dropping and truncating tables/databases  
- Checking data types using `information_schema`

---

### 🧠 What I Learned
Today, I learned how to:
1. **Create a database** and switch between databases using `USE`.  
2. **Design a table** with `PRIMARY KEY` and `UNIQUE` constraints.  
3. **Insert multiple rows** into a table in one query.  
4. **Alter table structure** by adding, renaming, or removing columns and defaults.  
5. **Update specific records** based on a condition.  
6. **Delete data** and understand the difference between `DELETE`, `DROP`, and `TRUNCATE`.  
7. **Fetch column details** using `information_schema` to analyze data types.
